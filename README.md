# 📡 Python Information Lab

Explore information representation, compression, error correction, and probabilistic data structures with Python.

Created by **python_scripts (Abhijith Warrier)**.

Understand how information is encoded, compressed, checked, and recovered. Each topic connects a foundational idea to a small Python implementation and an observable result.

---

## 📚 Learning Roadmap

The following topics describe the planned scope of the series. This roadmap is not a list of already published notebooks.

| Area | Concepts |
|---|---|
| **Representing information** | Bits, bytes, Unicode, UTF-8, and encoding. |
| **Compression** | Entropy, run-length encoding, Huffman coding, and dictionary compression. |
| **Detecting and correcting errors** | Checksums, hashes, parity bits, and Hamming codes. |
| **Approximate representations** | Bloom filters, Count-Min Sketch, and HyperLogLog. |
| **Sampling signals** | Digital sampling and aliasing. |

## 🚀 Getting Started

Once this repository and its notebooks are available, clone it:

```bash
git clone https://github.com/abhijithwarrier/Python-Information-Lab.git
cd Python-Information-Lab
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Install and launch JupyterLab:

```bash
python -m pip install jupyterlab
python -m jupyterlab
```

Use `python3` instead of `python` where required by your system. Open a notebook and run its cells from top to bottom. Any topic-specific packages and Python-version requirements will be stated in that notebook; install packages using its dedicated installation section.

---

## 🔍 Learning Approach

Examples will make distinctions such as detection versus correction, exact versus approximate answers, and storage savings versus information loss explicit. Simplified implementations are for learning, not substitutes for audited security primitives.

Run the example, change an input or assumption, and explain why the result changed. Keep the conceptual lesson connected to the code and its output.
